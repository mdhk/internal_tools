# CPC model
The `model.py` and `config.py` files in this directory adapt code from the [CPC model repository](https://github.com/facebookresearch/CPC_audio/tree/main), as released with the paper [Unsupervised Pretraining Transfers Well Across Languages
](http://doi.org/10.1109/ICASSP40776.2020.9054548) (ICASSP 2020). This code is MIT licensed, as found in the LICENSE file.

The `cpc_utils.py` file contains code for handling CPC models for use within `internal_tools`.
