# SpidR model
The `model.py`, `config.py`, `components.py`, `metrics.py` and `dinosr.py` files in this directory are copied from the [SpidR model repository](https://github.com/facebookresearch/spidr/tree/main), as released with the paper [SpidR: Learning Fast and Stable Linguistic Units for Spoken Language Models Without Supervision
](https://openreview.net/pdf?id=E7XAFBpfZs) (TMLR 2025). This code is shared under the CC BY-NC 4.0 License, as found in the LICENSE file.

The `spidr_utils.py` file contains code for handling SpidR models for use within `internal_tools`.
